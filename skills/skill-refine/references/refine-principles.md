# Refine Principles

Use these principles when rewriting a skill directory's Markdown.

## Core Rule

Refine the writing without changing the skill's intended behavior.

This means:

- improve the structure
- improve the expression
- improve the medium choice
- improve directory coherence

This does **not** mean:

- adding new product behavior
- changing scripts or code
- changing the skill's core scope without evidence from the directory

## What "better Markdown" means here

Markdown quality is high when it is:

- **clear** — the reader sees the main line quickly
- **concise** — low filler, low repetition, low commentary
- **accurate** — wording matches real intent and file role
- **forceful** — reads like an execution document, not a vague explainer
- **well-structured** — headings, tables, lists, and diagrams express the shape of the information

## Rewrite posture

- Be surgical about meaning.
- Be aggressive about weak expression.
- Be conservative about adding new content.
- Prefer reorganization over expansion.
- Prefer stronger forms over longer prose.
