# Editorial Criteria

## Include

Items that change what an AI builder should DO or THINK today:

- New tool/library release with immediate practical use
- Workflow or method with reproducible steps
- Architecture insight backed by real project experience
- Official product update that affects development workflow
- Failure analysis or postmortem with lessons

## Exclude

- Funding/valuation news
- Pure benchmark comparisons without practical takeaway
- Hype/speculation without evidence
- Retweets or reposts without original commentary
- Content older than 48 hours (unless just surfaced)
- Paywalled content with no accessible summary

## Tier Assignment

| Tier | Criteria | Count |
|---|---|---|
| L1 Headline | Changes immediate decisions; affects multiple builders; first to report | 1-2 |
| L2 Picks | Worth knowing; practical value; from trusted source | 5-10 |
| L3 Radar | Not yet confirmed; emerging pattern; worth tracking | 2-5 |

Target total: 10-15 items (~10 min read).

## Writing the Verdict

Each item needs a "对你意味着什么" (What this means for you) field.

| Rule | Detail |
|---|---|
| Voice | First person "你" addressing the reader |
| Length | One sentence, max two |
| Core question | "Should I change what I'm doing?" |
| Grounding | Connect to builder's daily work, not abstract trends |
| L2 vs L3 gate | If no clear action → it belongs in L3 Radar, not L2 |

Bad: "这对 AI 行业有深远影响。"
Good: "如果你在用 RAG pipeline，这个新的 chunk 策略可以直接替换现有方案。"
