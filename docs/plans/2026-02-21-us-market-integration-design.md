# 美股行情集成设计

**日期**: 2026-02-21
**状态**: 已批准

## 背景

a-share-review-planner 的分析框架第一步已提到"美股前一日表现"，但目前依赖从新闻文本中粗略提取，缺乏结构化数据。本设计在现有框架中集成美股行情，提供指数与核心科技股的量化数据，并基于硬编码的 A 股板块映射输出独立的"美股影响评估"结论，为选股和仓位决策提供新维度。

## 需求确认

- 数据来源：Yahoo Finance（yfinance，免费无需账号）
- 集成方式：独立输出"美股影响评估"章节，不直接修改大盘强弱评级
- 板块映射：硬编码在 `us_market.py` 顶部常量

## 影响强度阈值

| 涨跌幅 | 判断 |
|--------|------|
| ≥ +2% | 强利好 |
| +0.5% ~ +2% | 弱利好 |
| -0.5% ~ +0.5% | 中性 |
| -2% ~ -0.5% | 弱利空（承压） |
| ≤ -2% | 强利空（重挫） |

VIX 参考：< 20 正常 / 20–30 警戒 / > 30 恐慌
