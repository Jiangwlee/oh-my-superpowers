# OpenClaw Trading Agent Design

> Scope: A-share trend trading execution system using HTTP/WebSocket jvquant APIs.

## Goal
Build a robust autonomous trading assistant that executes daily plans, manages intraday risk, and evolves parameters after market close.

## Hard Rules
1. Universe is generated by existing review-selector skill.
2. Max concurrent symbols is 5.
3. Daily limit is 10 fills (counted by fills, not order submissions).
4. Single order target amount is <= 5000 CNY.
5. Exception: if previous close * 100 > 5000 CNY, one lot is allowed.
6. Add only when price reaches the next +2% level from the most recent buy price.
7. Stop loss is 20% below the most recent buy price.
8. Repost of first open order is allowed and capped at 5 times per symbol per day.
9. Intraday actions are limited to cancel/stop_loss/take_profit/reduce/add/repost_open.
10. Buy price policy is market price +1%; sell price policy is market price -1%.

## Skill Boundaries
1. `review-selector`: outputs candidate pool and draft plan.
2. `plan-compiler`: normalizes draft into executable plan.
3. `event-executor`: creates order intents from events.
4. `risk-gate`: final allow/reject decision with rule IDs.
5. `broker-adapter-jvquant`: executes only allowed intents.
6. `reflection-evolver`: proposes next-day parameter updates.

## Runtime Flow
1. EOD review: generate candidate pool and plan draft.
2. Pre-open: compile plan and initialize runtime state.
3. 09:30-09:35: execute opening batches from plan.
4. Intraday: event -> intent -> risk gate -> broker execution -> ledger.
5. Post-close: summarize and produce parameter suggestions for T+1.

## Data Layout
- `data/pools/YYYY-MM-DD/`
- `data/plans/YYYY-MM-DD/`
- `data/events/trade_events.jsonl`
- `data/orders/YYYY-MM-DD/`
- `data/positions/YYYY-MM-DD/`
- `data/params/active.yaml`
- `data/params/history/`
- `data/metrics/daily_metrics.csv`

## Notes
- Trade APIs must use jvquant HTTP endpoints.
- Non-trade data can use cost-aware routing (jvquant SQL or crawler).
- Rollback decisions are manual by user.
