# n8n 部署指南

## 概述

n8n 是工作流自动化工具，用于编排 ashare-data 的定时采集任务。

## 前置条件

- Docker 和 Docker Compose 已安装
- `infra_net` 网络已创建（见 Infrastructure 配置）
- PostgreSQL 数据库运行中（可选，用于持久化）

## 快速启动

```bash
cd /home/bruce/Dockers/N8N
docker compose up -d
```

## 访问 n8n

- **UI**: http://localhost:10003
- **API**: http://localhost:10003/api/v1

## 配置

### 环境变量

在 `docker-compose.yml` 或 `.env` 文件中配置：

```bash
# 数据库配置（PostgreSQL）
DB_TYPE=postgresdb
DB_POSTGRESDB_DATABASE=n8n
DB_POSTGRESDB_HOST=postgres
DB_POSTGRESDB_PORT=5432
DB_POSTGRESDB_USER=postgres
DB_POSTGRESDB_PASSWORD=your_password

# n8n 配置
N8N_PORT=5678
N8N_PROTOCOL=http
N8N_HOST=localhost
GENERIC_TIMEZONE=Asia/Shanghai

# 安全设置
N8N_SECURE_COOKIE=false  # 开发环境可设为 false
```

### 基本认证（可选）

如果启用基本认证：

```bash
N8N_BASIC_AUTH_ACTIVE=true
N8N_BASIC_AUTH_USER=admin
N8N_BASIC_AUTH_PASSWORD=your_password
```

## 数据目录

n8n 数据挂载到宿主机：

```yaml
volumes:
  - ./n8n_data:/home/node/.n8n
```

包含：
- 工作流文件
- 凭证配置
- 执行历史

## 集成 ashare-data

### 1. 确保 task-runner 运行

```bash
cd /home/bruce/Dockers/TaskRunner
docker compose up -d
```

### 2. 导入工作流

1. 打开 n8n UI: http://localhost:10003
2. Settings → Import from File
3. 选择 `/home/bruce/Projects/oh-my-superpowers/deployment/workflows/ashare-daily-simple.json`
4. 激活工作流

### 3. 验证连接

在 n8n 中测试 HTTP Request 节点：

```bash
# 从 n8n 容器内测试
docker exec n8n_app wget -qO- http://task_runner:8000/health
```

预期输出：`{"status":"ok"}`

## 维护

### 查看日志

```bash
docker logs n8n_app -f --tail 50
```

### 重启服务

```bash
docker compose restart
```

### 更新版本

```bash
docker compose pull
docker compose up -d
```

## 故障排查

### 问题：无法访问 n8n UI

**检查**:
```bash
docker ps --filter name=n8n_app
docker logs n8n_app --tail 100
```

### 问题：数据库连接失败

**检查**:
```bash
docker ps --filter name=postgres
docker exec postgres pg_isready -U postgres
```

### 问题：工作流不触发

**检查**:
1. 工作流是否已激活（开关 ON）
2. Cron Trigger 时间设置是否正确
3. n8n 容器时区：`docker exec n8n_app env | grep TZ`

## 备份

定期备份 n8n 数据：

```bash
tar -czf n8n_backup_$(date +%Y%m%d).tar.gz ./n8n_data
```
